Lucide icons (24×24 viewBox, `stroke="currentColor"`, 2px stroke, round caps/joins), copied from `assets/icons/`.

- Placed with `<img>`, so they render **black** (currentColor can't inherit). In dark mode invert them: `filter: invert(1) brightness(1.2)`.
- Sizes: 20px in contact rows and accordions, 22px in service rows, 24px in the claim card.
- Exceptions: `whatsapp.svg` is a filled Simple Icons mark (forced white on the WhatsApp button); `seatbelt.svg` and `helmet.svg` are custom drawings, recolored to `currentColor` so they invert in dark like the others.
- Editor set (bold, italic, heading-1/2/3, list, list-ordered, table-2, quote, link, image, strikethrough, text-align-*) is used by the admin Markdown editor only.
