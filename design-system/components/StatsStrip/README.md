# StatsStrip

Three real figures under a 2px rule, in the About section.

**Markup:** `.stats` > `.stats__item` > `p.stats__number` + `p.stats__label`.

- Numbers: `stat-number` (Space Grotesk, fluid to 56px, line-height 1) in `text-primary`; labels `body` 500 in `text-secondary`.
- Mobile: stacked rows with 1px `rule` between. From 768px: three columns split by 1px vertical `rule`.
- Only true figures from the business (+25 años, +8 aseguradoras, 24/7). No filler stats.
